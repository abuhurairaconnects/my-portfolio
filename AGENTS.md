## 2. Technical Stack & Deployment Targets
- **Framework**: Next.js 15 (App Router, Server Components) + React 19 + TypeScript (Strict mode).
- **Styling**: Tailwind CSS with Swiss Architectural Noir tokens (`#08090D`, `#11131A`, `#10B981`).
- **Typography**: Space Grotesk (Display), DM Sans (Body), JetBrains Mono (Tech tags).
- **Deployment**: Coolify VPS via multi-stage minimal `Dockerfile` with `output: 'standalone'`.
- **Healthcheck**: `/api/health` returning 200 OK for Traefik proxy monitoring.

---

## 3. Strict Quality & Anti-Slop Rules
- **No Purple-Blue SaaS Gradients**: Solid obsidian noir backgrounds with architectural hairline borders (`#1E2230`).
- **No 3-Card Clichés**: Project showcases must use asymmetric Bento Grids (1 Master Feature + 2 Flanking Cards).
- **No Invented Metrics**: All statistics must tie to authentic, verified production projects (Madrasa Management System, Joruri Rokto, Smart Voice Farm Accountant).
- **Zero TODOs / Placeholders**: Guarded by `strict-watchdog`. Every component is fully implemented.
